# iOS, tvOS, Android

The iOS, tvOS, and Android apps are FreqScene viewers, where you connect to hosts and render the visualizations through it. By themselves they do not generate visualizations through their system audio.

## Before you start

You need a computer on the same network running FreqScene as a host, either the [desktop app](desktop.md), a [kiosk app](kiosk.md), or the [controller](controller.md).

## Connecting

1. Open the app. The opening screen will list every host that can be found if it's broadcasting.
2. Setup the pairing process. If it's already paired, it should launch.
3. It should then launch the visualization and connect to the remote host.

If the host asks for pairing, you'll get a prompt — see below.

The app is set up to stay alive as long as it's on screen.
