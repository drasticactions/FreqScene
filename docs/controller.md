# Controller

FreqScene.Controller is a console app that can be used as a host to capture audio and send visualization data to other FreqScene instances. By itself, it does not render visualizations.

## Setup

Setup is similar to the [Desktop](desktop.md) program. You add `.milk` presets and textures, and pair clients to your host instance. For setting up the remote sessions, read the [Remote Viewing](remote-viewing.md) docs.
